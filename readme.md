# BidNa – Online Auction Mobile Application

## Core Idea
BidNa (บิดนะ) คือแอปพลิเคชันสำหรับ **การประมูลสินค้าออนไลน์** ที่เน้นความน่าเชื่อถือและความเป็นกลาง  
แก้ปัญหาการซื้อขายแบบประมูลในกลุ่มชุมชนเดิมๆ ที่มักสับสนเรื่องลำดับการบิดและเวลาปิดประมูล ช่วยให้ผู้ขายและนักสะสมสามารถซื้อขายได้อย่างมั่นใจ มีระบบจัดการที่เป็นธรรมและตรวจสอบได้

---

## MVP Features

### 1) Authentication & User Management
- ระบบสมัครสมาชิกและเข้าสู่ระบบ
- รองรับการใช้งานผ่าน Email หรือ Social Login

### 2) Product Listing
- ผู้ขายสามารถสร้างรายการสินค้าประมูลได้ (ลงรูป, รายละเอียด)
- กำหนดราคาเริ่มต้นและเวลาปิดประมูลได้เอง

### 3) Real-time Bidding Core
- ระบบกดเสนอราคาที่อัปเดตทันที (Real-time)
- **Bid History:** แสดงตารางประวัติผู้ที่มาประมูลล่าสุดอย่างชัดเจน

### 4) Precision Timer
- **Countdown Timer:** หน้าจอแสดงเวลานับถอยหลังก่อนปิดการประมูลที่แม่นยำ

### 5) Personal Dashboard
- หน้าเมนูสำหรับดูรายการสินค้าที่ตัวเองลงขาย
- หน้าเมนูสำหรับดูรายการสินค้าที่กำลังร่วมประมูล

### 6) Simple Notification
- แจ้งเตือนพื้นฐานเมื่อการประมูลสิ้นสุด หรือมีคนให้ราคาสูงกว่า

---

## Nice-to-Have Feature

### 1) Push Notification
- ระบบแจ้งเตือนเด้งทันทีเมื่อมีคนลงราคาแข่ง (Real-time Alert)

### 2) Payment Gateway Integration
- ระบบชำระเงินผ่านแอปทันทีเมื่อชนะการประมูล
- รองรับ **PromptPay** หรือการ **ตัดบัตรเครดิต**

### 3) Chat System
- ระบบแชทพูดคุยระหว่างผู้ซื้อและผู้ขาย
- เปิดใช้งานได้หลังจากจบการประมูลแล้วเท่านั้น

### 4) Watchlist / Favorite
- ระบบกดติดตามสินค้าที่สนใจ
- มีการแจ้งเตือนเตือนล่วงหน้าก่อนปิดประมูล

### 5) Rating & Review
- ระบบให้คะแนนผู้ขายเพื่อสร้างความน่าเชื่อถือ (Credit scoring)

### 6) Search & Category Filter
- ระบบค้นหาสินค้าอย่างละเอียดตามหมวดหมู่
- ระบบกรองสินค้าตามช่วงราคา
